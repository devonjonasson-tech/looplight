# Looplight
A playable mobile-friendly prototype with ten handcrafted puzzles, branching light paths, optional synthesized sound, undo, hints, level selection, and locally saved progress.

Open index.html in a browser, or serve this folder with `python3 -m http.server 8080` and open the local server. No build or package install is required. The optional Google font falls back to system fonts when offline. Game logic and assets are local; sound starts only after enabling it.

This is a browser prototype, not a signed iOS application. App Store delivery still requires native packaging, device testing, Apple Developer enrollment, app icons and screenshots, privacy disclosures, purchase-price configuration, and App Review. No payments or analytics are implemented. The tentative title has not been checked for trademark or App Store availability.
